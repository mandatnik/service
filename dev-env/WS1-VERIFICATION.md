# Проверка подготовки окружения на WS1

Дата: 15.11.2026. Узел: WORKSTATION-1 (`192.168.189.136`), Windows 10
Enterprise 19045, Windows PowerShell 5.1. Проверка выполнялась под существующей
административной учётной записью стенда. Это существующая Windows с CSP/агентом,
а не переустановленная ОС; перед проверкой Git, Go, Node и Make через PATH
не находились, системный PATH содержал только каталоги Windows.

## Что сделано

- Размещена копия исходников без секретов и Git-метаданных в `C:\project`.
- Выполнен `dev-env\prepare-windows.ps1 -SourcePath C:\project`.
- Установлены Chocolatey 2.7.5, Git 2.56.1, Go 1.26.3, Node.js 22.22.3
  (npm 10.9.8), Make 4.4.1, WiX Toolset 3.14.1.
- .NET Framework 4.8 уже присутствовал; его установщик не запускался.
- OpenSSL 3.5.9 доступен из Git for Windows.
- Повторный запуск скрипта завершился успешно без переустановки инструментов.

## Исправления скрипта

PATH сохраняется в системном окружении через API .NET без `setx`, чтобы не
обрезать длинное значение. В него добавляются Go, Node, Git, OpenSSL, Make
(Chocolatey shim) и WiX. `WIX_DIR` сохраняется на уровне компьютера.
Explorer получает уведомление об изменении окружения; уже открытые окна
нужно заменить новыми, при сохранении старого окружения — перелогиниться
или перезагрузиться.

Текущему пользователю предоставляется Modify на найденную папку исходников,
чтобы распакованный повышенным процессом проект оставался доступен ему для
сборки. Доступ к данным действующего агента/серверным секретам не менялся.
У загрузок отключён медленный прогресс PowerShell и задан тайм-аут 180 секунд.

## Результат

В **новом SSH-сеансе**, без refreshenv и ручного присваивания PATH:

```powershell
cd C:\project
make build
```

Успешно собраны Vue-интерфейс, `mandatnik-agent.exe`,
`mandatnik-backend.exe`, `mandatnik-acceptance.exe`, `build-info.json`
и `SHA256SUMS` в `C:\project\artifacts\ci`.

Повторный запуск `make build` через отдельный процесс планировщика также
завершился кодом 0. Временная задача удалена. Хотя запрашивался Limited,
процесс фактически сохранил административный токен: отдельная проверка
полностью непривилегированного пользователя не подтверждена.

`make msi` в новом сеансе без аргумента WIX_DIR также завершился успешно:
`C:\project\artifacts\ci\MandatnikAgent-0.5.0.msi`, 3 497 984 байта.
SHA-256 этой конкретной сборки:
`4a663af2c8fe19c7dcc3ff29d2da3bb603a3232aad78fe2e7e5b9a63ec7a5773`.
Перезагрузка для описанных проверок не потребовалась.

Журналы на WS1:

- `C:\MandatnikDev\logs\prepare-*.txt` — установка и повторный запуск;
- `C:\project\ws1-make-build.log` — первая сборка;
- `C:\project\ws1-limited-build.log` — повторная сборка, включая фактический токен;
- `C:\MandatnikDev\environment.json` — окружение.

## Границы проверки

Не запускались необязательные установщики SQL/SSMS, полный `-Build`
(unit/vet/package) и перезагрузка. Проверены именно подготовка инструментов,
`make build` и `make msi`. Исходники переданы архивом, поэтому commit в
метаданных сборки — `unknown`; при сборке из Git будет ревизия checkout.
Backend и MSI не устанавливались, действующий агент не заменялся. Мастер
backend setup/configure в этой ревизии по-прежнему отсутствует.
