# Приёмка P02–P03: Go-служба, профили и лицензии CSP

Дата: 2026-11-14. Стенд: `.136` (CSP 5.0.13003) и `.137` (CSP 4.0.9963).
Служба `TelehackAgent` установлена как LocalSystem, запущена через SCM.
Сбор выполнялся продуктовым Go-кодом; C#/PowerShell использовались только
для установки тестовых фикстур.

## P02: профили, хранилища и `.cer`

### Что проверено

- Настоящая SCM-служба: `NT AUTHORITY\SYSTEM`, SID `S-1-5-18`, session `0`.
- `.136`: 5 профилей; `.137`: 5 профилей. Системные профили исключены.
- Незагруженные пользователи:
  - `.136` `user1` (`S-1-5-21-...-1106`) — 3 сертификата;
  - `.137` `user2` (`S-1-5-21-...-1107`) — 3 сертификата.
  Хранилище прочитано через временное подключение `NTUSER.DAT` и
  `CERT_STORE_PROV_REG`; после сбора hive выгружен.
- Вошедший пользователь `agent` — 5 сертификатов из файлового
  user-MY-хранилища `%APPDATA%\Microsoft\SystemCertificates\My`.
- Вошедший `mimbol` (RDP-сессия) — логическое MY через токен сессии;
  элемент CryptoPro неизвестного файлового формата не разбирался вручную,
  а был прочитан через CryptoAPI. Пользовательские данные не изменялись.
- Папка `C:\ProgramData\Telehack2026\test-certs`: 8 уникальных сертификатов
  из 9 файлов (DER, PEM и дубль DER). Дубликат не создал вторую запись
  сертификата; путь файла сохранён.
- Повреждённый `.cer`: источник `complete=false`, остальные 8 сертификатов
  сохранены; после удаления файла источник снова `complete=true`.
- Все SHA-256/серийные номера фикстур совпадают с `manifest.json`
  (`matches_manifest=true` для всех проверенных).
- После сбора нет `HKU\Telehack*`; `user1`/`user2` остались `Loaded=false`.
  Собственное MY службы не использовалось.

### Ограничения

- Файловое MY-хранилище незагруженного пользователя с **простым** элементом
  (40-байтный заголовок + DER) поддерживается. Элементы закрытого формата
  CryptoPro для незагруженного пользователя не разбираются; источник
  помечается `partial`, если такой элемент встретится. Для загруженного
  пользователя используется его токен сессии и логическое MY, поэтому
  формат файла не важен.
- Перенаправленные/роуминговые профили с нестандартным `AppData` покрываются
  через `User Shell Folders` только при доступном hive; иные варианты —
  явный `partial`.
- Токены, PIN и закрытые ключи не читаются. Системные/машинные stores
  исключены.

### Доказательства

- `evidence/p02/136.json`, `evidence/p02/137.json` — санитизированные
  сводки: identity службы, профили, полнота, счётчики, fixture SHA-256,
  CSP/license; без DER и без данных не-фикстурных сертификатов.
- Команда: `tools/stand/summarize-diagnostics.ps1` (диагностический
  инструмент, не входит в продукт).

## P03: версии и лицензии КриптоПро

| Параметр | `.136` | `.137` |
| --- | --- | --- |
| Product version (release) | **5.0.13003** | **4.0.9963** |
| Core version | **5.0.10013** | **4.0.9019** |
| `license_kind_raw` (COM GetType) | **0** | **1** |
| `license_kind` | **client** | **server** |
| `kind_source` | CPCSPLicense.GetType | CPCSPLicense.GetType |
| `license_state` | active | active |
| `valid_to_raw` (COM) | 2027-02-14T18:59:59 | 2027-02-14T18:59:59 |
| `time_basis` | system_local_assumed | system_local_assumed |
| `is_trial` | unknown | unknown |
| `term_kind` | time_limited | time_limited |

- Release-версия получена из `csptest -keyset -verifycontext -silent`
  (Release Ver) и не подменена версией DLL; core-версия — отдельное поле.
- Тип не выводится из версии CSP/Windows. Коды 0/1 сопоставлены с
  client/server на проверенных сборках; иные коды — `unknown` с сохранением
  raw. CAdES не требуется.
- COM-объект создаётся и освобождается в одном STA-потоке; варианты,
  `IDispatch` и `IUnknown` освобождаются. Номер лицензии не читается и не
  логируется.
- `valid_to_raw` хранится без часового пояса; `valid_to_utc` — явно
  помеченная интерпретация (`system_local_assumed`), а не доказанный UTC.
- Встроенная лицензия: детектор документированного OID `1.2.643.2.2.49.2`
  реализован и проверен синтетическим расширением; реального образца
  встроенной лицензии в фикстурах нет — это явно отмеченный пробел, а не
  выдуманный результат. Фикстуры не выдаются за лицензированные.
- Отсутствие CSP — отдельное успешное состояние (`present=false`,
  `license.state=not_installed`); ошибка COM/неизвестный код дают
  `partial`/`unknown`, а не ложную классификацию.

## Команды проверки

```powershell
telehack-agent.exe status
telehack-agent.exe diag
Get-Content C:\ProgramData\Telehack2026\Agent\logs\current.txt -Tail 30
Get-ChildItem Registry::HKEY_USERS | Where-Object { $_.Name -match 'Telehack' }
```

Логи и сводки не содержат приватных ключей, паролей или номеров лицензий.
