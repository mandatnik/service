# Интеграция удалённой активации в main

Дата: 14.11.2026. Объединены `main` и `feature/remote-activation-tasks`.

Сохранены название «Мандатник», логотипы, светлая/тёмная/системная темы,
компоновка сайдбара, копирайт и окно авторов. Новые разделы «Пулы лицензий»
и «Задачи» включены в существующую навигацию.

## Исправления при интеграции

- Подключён отсутствовавший импорт `ActivationModal` в `TasksView`.
- Модалка активации использует нативный `dialog`: блокировка фонового
  интерфейса, фокус, Escape и возврат фокуса к открывшей кнопке.
- Новые экраны используют общие цвета тем; добавлены иконки, подписи фильтров,
  открытие строк таблиц клавишей Enter и адаптация модалки к узкому экрану.
- При выборе пула устаревший ответ не подменяет текущие данные. Смена пула
  очищает незавершённый импорт и блокировку; переименование использует ID
  выбранного для переименования пула.
- Предпросмотр активации не запускается дважды при первой загрузке пула;
  устаревшие ответы после закрытия или нового запроса игнорируются.
- POSIX-проверка chmod выделена в Unix-тест. Windows-тест проверяет реальный
  защищённый DACL файлов keyring и HMAC: текущий пользователь, SYSTEM и
  Administrators, без посторонних ACE.
- `make integration` и `make test-e2e` запускают оба набора SQL-тестов:
  `TestPoliciesSQLServer` и `TestTasksSQLServer`.
- Приёмочный клиент очищает созданные им scan task items/events, capabilities,
  encryption keys и observation bindings до удаления тестовых регистраций.
  Изменение порядка очистки проверено полным HTTPS-сценарием.

- `make check`: Go unit и go vet — PASS.
- `make build`: embedded Vue bundle и Windows amd64 EXE — PASS.
- `make integration E2E_CONFIG=.secrets/acceptance.json`: политики и девять
  SQL-подтестов задач — PASS на реальном SQL Server стенда.
- `make test-e2e E2E_CONFIG=.secrets/acceptance.json`: новый временный backend
  на loopback-портах, подписанный HTTPS-контракт, legacy jobs, отчёты,
  rename/replay и очистка синтетических записей — PASS. Локальное свидетельство:
  `evidence/local/merge-activation/contract-20261114T151539Z.json`.
- На Windows Server стенда выполнены тесты `licensecrypto` (включая ACL) и
  `winapi` (memory store и provider properties реального CryptoAPI context) —
  PASS. Временные test EXE удалены; продуктовые службы не заменялись.
- В браузере на локальных контрактных данных проверены пулы и активация из
  раздела задач, светлая/тёмная темы, Escape и экран шириной 390 px без
  горизонтального переполнения модалки.

## Границы проверки

Эти результаты не подтверждают применение нового платного ключа или полный
цикл новой Windows-службы `install_license`. Ограничения такой приёмки
сохранены в [REMOTE-ACTIVATION-0.5.0.md](REMOTE-ACTIVATION-0.5.0.md).
Продуктовые backend/агенты на стенде в ходе интеграции не обновлялись;
SQL-проверки используют ранее подготовленную стендовую БД.
