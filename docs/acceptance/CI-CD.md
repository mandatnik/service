# Проверка CI/CD — 14.11.2026

Репозиторий: http://10.10.26.11/pdoexception/telehack2026.
Раннеры: mandatnik-linux-140 (Ubuntu, пользователь mimbol) и
mandatnik-windows-138 (Windows Server, SYSTEM для WiX ICE).
Регистрация ограничена этим репозиторием. Оба запускаются автоматически при
старте ОС. Производственные службы агента и бэкенда при настройке не заменялись.

Проверены вручную:

- `make check` и Windows cross-vet;
- `make build`: Vue/Vite, три Windows amd64 EXE, build-info и SHA256SUMS;
- `make test-e2e`: отдельный новый backend с временным TLS на loopback,
  реальные SQL Server проверки, 72 контрактные проверки и удаление своих записей;
- Linux `make msi` с MSI_HOST: упаковка через Windows SSH, скачивание MSI,
  удаление временного каталога. Windows SSH-соединение использовалось только
  для проверки; пароль не сохранялся, ключи авторизации не добавлялись.

Проверки в самом Gitea, включая журналы и скачиваемые артефакты:
[Actions](http://10.10.26.11/pdoexception/telehack2026/actions).
Для конкретной ревизии открывайте запуск с соответствующим SHA.

Первоначальные Windows проверки нашли ранее скрытые проблемы:

1. Unit-тесты очереди применяли SYSTEM-only ACL к собственным временным
   файлам и теряли доступ под LocalService. Для тестирования порядка/удаления
   выделена подмена файловой защиты, в настоящем агенте по умолчанию остаются
   прежние SYSTEM/Administrators ACL. Unit-тесты после исправления прошли
   под LocalService до перевода MSI-раннера на SYSTEM.
2. Windows go vet обнаружил преобразование uintptr в указатель CERT_CONTEXT.
   Оно заменено типизированной функцией x/sys/windows. Добавлен Windows-тест
   настоящего хранилища в памяти: пустой результат, добавление временного
   сертификата, точное совпадение DER, повторное перечисление. Профили и
   установленные сертификаты этот тест не меняет.

3. Windows Git преобразовывал миграции LF → CRLF, меняя встроенный checksum.
   Добавлен `.gitattributes` с фиксированным LF; миграции и сохранённые в SQL
   контрольные суммы не переписывались.

WiX ICE не смог работать под LocalService; Windows-раннер переведён на SYSTEM
с отдельными защищёнными рабочим каталогом и кэшем. Валидация ICE сохранена,
подавление ошибок -sval не добавлялось.

тестов: [CONTRIBUTING.md](../../CONTRIBUTING.md).
