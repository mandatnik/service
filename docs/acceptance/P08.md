## Ограничения

- Известное ограничение сбора: сложный file-store элемент **выгруженного**
  профиля `mimbol` даёт `partial`; это не маскируется, а показывается в
  источниках. Загруженные профили используют logical MY и собираются.
- Админка не выводит тип лицензии из версии Windows/CSP и не помечает
  server license на Windows 10 ошибкой.
- Ручное сканирование доставляется на следующем опросе; ускоренного
  производственного интервала нет.
