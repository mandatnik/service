# Таблица сертификатов

Столбцы: Владелец, УЦ, АРМ, Встроенная лицензия, Срок, Статус.

Имена и реквизиты владельца и УЦ читаются отдельно из subject/issuer DER.
Должность — атрибут title (2.5.4.12), а не подразделение OU. Для представителя
ЮЛ используются surname и givenName. Только полностью прописные личные имена
приводятся к регистру «Каждое Слово»; названия организаций и УЦ сохраняются.
Длинный подзаголовок занимает одну строку с многоточием; полное значение доступно
при наведении. Почта в баджах открывает mailto, не карточку сертификата.

API списка и интеграционного списка дополнен owner_details, issuer_details,
registry_machines и file_machines. Старые поля сохранены. Счётчики считают
DISTINCT machine_id среди активных наблюдений: отдельно user_store и folder.
Число мест обнаружения равно machines, а не observations и не сумме источников.

Статус вычисляется по not_before/not_after. Границы интервала включены.
Отзыв показывается только при явном revocation_status=revoked; действующий
backend пока не собирает этот результат и не выполняет CRL/OCSP-проверку.
«Действующий» обозначает срок действия, не доверие цепочке или отсутствие отзыва.
При неизвестном результате определения встроенной лицензии остаётся
«Не определено», чтобы отсутствие данных не выдавалось за «Нет».
