# Обзор и фильтры АРМ

Раздел «Обзор» содержит четыре основных счётчика и мониторинг лицензий/сертификатов.
Из интерфейса удалены последний отчёт, отчёты/события за сутки, конфигурация и
блок «Что проверять». Старые поля API обзора сохранены для совместимости.

В мониторинге участвуют только неархивные машины с текущей активной регистрацией.
Онлайн — связь менее трёх минут назад. Считаются машины, а не регистрации.

- Активная лицензия: CSP обнаружен, источник сообщает license_state=active.
  Подсчёт пробных основан на is_trial=yes/true.
- Лицензия требуется: есть сертификат в личном реестре без встроенной лицензии,
  CSP обнаружен, обычной активной лицензии нет. Пробная не заменяет обычную.
  Если все сертификаты покрыты встроенной лицензией, машина не требует отдельной.
- Без КриптоПро: CSP не обнаружен; при отсутствии CSP-состояния это соответствует
  существующему состоянию карточки «CSP не установлен».
- Сертификат без замены: истёк за последний календарный месяц, имеет известный
  ИНН владельца, ещё наблюдается на текущем АРМ; в инвентаре нет действующего
  сертификата с тем же ИНН. Отсутствие ИНН не позволяет проверить замену, поэтому
  такие сертификаты в этот показатель не входят. Будущая замена не считается
  действующей. Дедупликация сертификатов — по SHA-256, АРМ — по machine_id.

Каждая плашка мониторинга открывает /arm с фильтром monitor. Ссылка «машин онлайн»
также открывает соответствующий набор. Рядом с числом сертификатов показано число
затронутых АРМ: один сертификат может встречаться на нескольких машинах.
Предикаты счётчиков и фильтров общие. as_of сохраняет момент расчёта временных границ
при переходе; новые отчёты могут изменить актуальные сведения о машинах.

Дополнительные фильтры: название, hostname, точный IP, связь, CSP, группа,
лицензия, сертификаты и статус. Они объединяются через AND и применяются на
сервере до подсчёта страниц. Фильтры записаны в URL, переживают обновление страницы
и навигацию назад. Можно снять только мониторинг или сбросить все фильтры.
Строка фильтров остаётся доступна и при пустом результате.

Проверки: frontend unit tests; тесты приложения; интеграционный тест
TestAdminMonitoringSQLServer на отдельной одноразовой SQL-базе
MandatnikMonitorTest_* (никогда на рабочей базе), включая состав выборок,
исторические/архивные карточки, календарную границу, замену по ИНН,
комбинации фильтров и дедупликацию источников сертификатов.
