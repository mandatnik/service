Перед публикацией проверены все 1099 достижимых исторических blob-объектов:
совпадений с заголовками закрытых ключей, шаблонами GitHub-токенов и AWS access
key не найдено; `.secrets`, `.env`, `.runner`, `.key`, `.pfx`, `.p12` в истории
не обнаружены. Это ограниченная проверка типовых сигнатур, а не гарантия
отсутствия любых секретов. Исходники и история включают стендовые адреса и
публичные синтетические сертификаты; локальные файлы доступа не публикуются.

Зеркало публикуется с main, ветками и тегами исходного репозитория Gitea.
Внутренние refs, рабочие копии, незакоммиченные изменения и файлы `.secrets`
не являются частью публикации. Релизные EXE/MSI и запуски Gitea Actions
не переносятся Git push; их перенос — отдельная операция. Автоматическая
постоянная синхронизация между Gitea и GitHub в этой задаче не настраивается.
